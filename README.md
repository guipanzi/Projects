# Projects
Portuguese Language Student Performance Analysis

Analyzed student performance data from Portuguese language courses to identify academic trends and factors influencing student success. Used Python for data cleaning, exploratory data analysis, visualization, and predictive modeling. Generated reports highlighting correlations between study habits, demographics, and academic outcomes.

Tools & Technologies: Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Jupyter Notebook

Key Features:

Data preprocessing and feature analysis
Statistical analysis and visualizations
Predictive modeling for student performance
PDF reports summarizing findings and insights


Predicting Credit Card Payment Default

Performed data preprocessing, exploratory data analysis, feature engineering, and model evaluation to improve prediction accuracy and understand financial risk patterns.

Tools & Technologies: Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, Jupyter Notebook

Key Features:

Financial data analysis and preprocessing
Classification model development
Model evaluation and performance comparison
Risk prediction and trend visualization
